The solver opened the school. Self-play let the students set their own exam questions. Unfortunately, the students were also writing the answer key.

What actually plays whom?

During self-play, the network plays both seats against itself, using Monte Carlo tree search and Dirichlet noise. It is not training by repeatedly challenging the solver. The solver still supplies hidden-layout samples and soft mine targets, and later serves as an evaluation opponent. Keeping those roles separate prevents a surprisingly durable misunderstanding of what the training loop is doing.

At a public position, the network proposes a distribution over legal actions and predicts a value. Search refines the action choice by simulating possible continuations. The game records training examples, finishes, and supplies outcome information. Training then fits the network to the search targets and game results. A completed iteration produces another generation, which can generate the next batch of games.

What search is searching

Monte Carlo tree search grows a partial tree instead of exhaustively considering every continuation. Selection follows promising edges. A new leaf is evaluated by the network. The result is backed up along the path so earlier decisions accumulate evidence. Repeating the process directs more simulations towards choices that appear useful while leaving room for exploration.

PUCT balances estimated action value against an exploration term that uses the policy prior. A high-prior move gets attention early; an already heavily visited move must justify further attention with its value. The exploration constant changes that trade-off. A policy prior is helpful guidance, but it can also become a rut if search never gathers enough contrary evidence.

The hidden board changes every simulation’s starting point. We sample a layout consistent with the public evidence, simulate actions on it, and organize outcomes by the public states those actions expose. The tree therefore pools evidence across plausible worlds rather than promoting one imaginary mine map to permanent truth. That is the information-set adaptation at the heart of this project.

The sign is not “minus every move”

Two-player value backups are often described as alternating signs each ply. That shortcut fails here. Finding a mine grants another move, so an edge need not change the player. Opening a safe cell passes the turn; a bomb also passes it. Values must remain attached to the correct player perspective, not to an assumption that every click alternates seats.

This is a good example of why adapting a famous algorithm is more than copying its name. Public-state identity, legal actions, turn transitions, and hidden-layout sampling all carry game-specific meaning. If one is wrong, a tree can be impressively busy while estimating the wrong question.

What the network learns

For ordinary PUCT, search visit counts become policy targets. The value head learns from game outcomes. The mine head receives soft probability targets from the solver. These signals are related but not identical: a good action can differ from the most certain mine, and a precise local probability need not imply a precise prediction of who wins.

Dirichlet noise encourages varied action choices during self-play rather than making every training game repeat the network’s current favourite line. Evaluation is different: it measures the player under the chosen test conditions. Later, leaving a different search algorithm’s exploration noise enabled during evaluation would produce a spectacularly misleading result. Randomness is a tool with a context, not seasoning to sprinkle everywhere.

Improvement is an experiment

The loop can reinforce its own habits. Sharp priors can generate sharp search targets; those targets can make the next prior sharper. More training does not automatically supply more diverse evidence. This matters later when policy targets concentrate on roughly five effective actions out of around 190–330 legal actions, while extra search still fails to establish a stronger player.

Self-play is powerful because each generation can ask harder questions. It is not a proof that it does. Held-out diagnostics and matches against older generations remain necessary. Otherwise the player is both setting the exam and announcing, with great confidence, that the examiner seems delighted.
